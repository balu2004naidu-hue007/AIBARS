# AIBARS Generated Artifacts Guide

The `artifacts/` directory contains reusable, machine-readable validation evidence generated by the project tools.

| File | Purpose |
|---|---|
| `synthetic_fault_dataset.csv` | Reproducible generated feature vectors and labels used to train/evaluate the advisory classifier. This is synthetic data, not captured sensor telemetry. |
| `fault_classifier_model.json` | Persisted Gaussian Naive Bayes class means, variances, priors and feature schema. |
| `ml_evaluation.json` | Synthetic hold-out evaluation, confusion matrix and per-class precision/recall/F1. |
| `advanced_system_report.json` | Aggregated campaign results, ML evaluation, risk distribution and per-scenario summaries. |
| `fleet_manifest.json` | Scenario-to-logical-device assignments, command outcomes and portable relative output paths. |
| `stress_campaign_report.json` | Seeded 48-run concurrency regression summary and invariant outcomes. |
| `final_validation_report.json` | Compiler/tool versions, test counts, campaign results, live API checks and explicit acceptance items still pending. |
| `SHA256SUMS.txt` | SHA-256 checksums for release files, generated after packaging contents are final. |

Each directory under `examples/advanced_runs/` contains `summary.json`, `events.jsonl`, and, for faulted runs, `incident.json`; it also contains `advanced_analysis.json` with the AI advisory and risk assessment.

The standalone dashboard at `examples/dashboard.html` embeds the current generated campaign records. It does not need a web connection for offline viewing. The local server adds fresh live simulator launches at `http://127.0.0.1:8765`.
